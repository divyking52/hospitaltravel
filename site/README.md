# Hospitality Cancún — Dentix-style Landing

React + Tailwind CSS + Framer Motion landing page modeled on the Dentix template architecture, filled with Hospitality Cancún / Costamed brand content.

## Run

```bash
cd site
npm install
npm run dev
```

## Edit brand content

All copy, colors, nav, and image URLs live in one place:

[`src/brand.js`](src/brand.js)

Swap headlines, CTAs, service cards, team portraits, and media URLs there — sections read from that config automatically.

## Stack

- Vite + React
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Framer Motion (hero stagger, scroll scrub text, marquees, reveals)
- Lucide React icons
